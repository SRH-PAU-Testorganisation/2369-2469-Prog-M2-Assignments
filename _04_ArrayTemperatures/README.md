# Temperaturen

## Aufgabe 1: Ein- und Ausgabe + Berechnungen
Lassen Sie einen Nutzer die Temperaturen von **sieben Tagen** im Terminal eingeben
und speichern Sie diese in einem Array. Orientieren Sie sich an der Aufgabe mit der
Notenliste. Geben Sie anschließend alle Temperaturen aus und berechnen Sie:

- die **Durchschnittstemperatur**
- die **höchste Temperatur**
- die **niedrigste Temperatur**

Eine mögliche Ausgabe könnte so aussehen:
```
Temperaturen:
18
21
19
16
24
22
20

Durchschnitt: 20.0
Höchste Temperatur: 24
Niedrigste Temperatur: 16
```

## Aufgabe 2: Temperaturen über dem Durchschnitt

Erweitern Sie die Temperaturaufgabe.
Geben Sie zusätzlich alle Temperaturen aus, die **über dem Durchschnitt** liegen.
Bei einem Durchschnitt von `20.1` könnte die Ausgabe bspw. so aussehen:

```
Temperaturen über dem Durchschnitt:
21
24
22
```
