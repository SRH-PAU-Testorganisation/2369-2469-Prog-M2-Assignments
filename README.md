# Modul 2: Arrays, Funktionen und co.

Wie schon in Modul 1 bearbeiten Sie im Verlauf des Unterrichts die Aufgaben in den Unterordnern.
Z. B.:
```
_01_For/
├── README.md
├── Task1_SumWithWhile.java
├── Task2_TableWithWhile.java
├── Task3_MissingUpdateWithWhile.java
└── Task4_WarumUpWithWhile.java
```

In den `README.md`-Dateien finden Sie die Aufgabenstellung für die Übung und/oder
zusätzliche Hinweise und Tipps.

Um sog. _Mergekonflikte_ zu vermeiden, arbeiten Sie bitte **nicht in den Lösungsordnern** wie
z. B. `_01_HelloWord_Solution/` und und  **nicht in Lösungsdateien** wie 
z. B. `_01_HelloWord/HelloWorld_Solution.java`
