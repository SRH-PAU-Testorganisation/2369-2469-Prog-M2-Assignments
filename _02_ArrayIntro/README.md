# Array Einführung

## Aufgabe 1
Legen Sie ein Array mit den folgenden fünf Zahlen an:
```text
10 20 30 40 50
```

Geben Sie anschließend die **erste**, **dritte** und **fünfte** Zahl aus:
```
10
30
50
```
Was passiert, wenn Sie versuchen den Wert bei Index `5` auszugeben?

## Aufgabe 2
Legen Sie folgendes Array an:
```
int[] zahlen = {10, 20, 30, 40, 50};
```

Verändern Sie anschließend den **zweiten** Wert auf `99` und den **letzten** Wert auf `77`.
Geben Sie danach alle fünf Werte einzeln (ohne Schleife) aus:
```
10
99
30
40
77
```

## Aufgabe 3
Legen Sie folgendes Array an:
```
int[] zahlen = {4, 7, 2, 9, 1};
```

Geben Sie alle Werte des Arrays mit einer **`for`-Schleife** aus:
```
4
7
2
9
1
```
Verwenden Sie dabei nicht für jeden Wert einen eigenen `IO.println()`-Aufruf.

## Aufgabe 4
Legen Sie folgendes Array an:
```
int[] zahlen = {4, 7, 2, 9, 1};
```

Geben Sie alle Werte des Arrays zusammen mit ihrem Index aus.
Die Ausgabe soll so aussehen:
```
Index 0: 4
Index 1: 7
Index 2: 2
Index 3: 9
Index 4: 1
```
Verwenden Sie eine `for`-Schleife.
