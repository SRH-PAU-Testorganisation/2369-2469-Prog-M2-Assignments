# Funktionen / Methoden

## Aufgabe 1
Initialisieren Sie einen beliebigen String.
Finden Sie heraus, wie Sie die folgenden Methoden auf dem String aufrufen, und weisen Sie
das Ergebnis der Methoden einer Variable vom passenden Datentyp zu:
1. `someStr.toUpperCase()`
2. `someStr.toCharArray()`
3. `someStr.contains()`

## Aufgabe 2
Definieren Sie eine weitere Funktion, die zwei `int`-Zahlen miteinander addieren soll. Der
Funktionskopf ist Ihnen schon vorgegeben:
```java
int add(int number1, int number)
```
Schreiben Sie nun den Funktionskörper (d.h. das tatsächliche Addieren der Zahlen mit Rückgabe des Ergebnisses) und platzieren Sie die Funktion an richtiger Stelle in Ihrer Datei.
Rufen Sie die Funktion anschließend in der Main-Methode mit den Werten `13` und `47` auf und
weisen Sie das Ergebnis einer passenden Variable zu.

## Aufgabe 3
Definieren Sie eine Funktion `calcPercent()`, die zwei Eingaben (d.h. Parameter) entgegennimmt:
- Eine Zahl (`double`)
- Einen Prozentsatz (`int`)

Die Funktion soll dann den angegebenen Prozentsatz der übergebenen Zahl berechnen und
das Ergebnis zurückgeben.

Beispiel: Für die Eingaben `200.0` und `25` soll das Ergebnis `50.0` herauskommen, weil dies
`25%` von `200` entspricht.
Rufen Sie die Funktion anschließend zweimal mit folgenden Eingaben in der Main-Methode
auf und weisen Sie die Ergebnisse je einer passenden Variable zu:
- `300.0` und `50` (gewünschtes Ergebnis: `150.0`)
- `222.2` und `20` (gewünschtes Ergebnis: `44.44`)
